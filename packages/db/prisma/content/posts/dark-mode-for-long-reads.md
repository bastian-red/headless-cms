A dark theme for a page you read for fifteen minutes is not the light theme with its colours inverted.

## Softer, not maximum, contrast

Pure white text on pure black looks sharp in a screenshot and glows after a few paragraphs. Our dark theme uses an off-white on a very dark grey. It still clears the contrast ratio the accessibility guidelines require for body text, with room to spare.

## A little more weight

Light text on a dark background looks thinner than dark text on a light one. Our body text is set slightly heavier in the dark theme so that both read as the same weight.

## Follow the reader's setting

The page follows the system preference. There is no toggle to find and no flash of the wrong theme on load, because the choice is made by the browser before the first paint.

## Check both

Every colour pair on the site is checked in both themes by a test that reads the real stylesheet. A colour that passes in light mode and fails in dark mode is caught before it ships.
